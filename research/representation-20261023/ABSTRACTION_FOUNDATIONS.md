# 状态抽象、部分可观测与反例精化：原始文献学习笔记

查阅日期：2026-10-23。

本文件属于研究管理侧资料，供协议设计、独立评估和复习使用。不得自动进入第二阶段学习者的挂载目录、提示词、技能、检索库或历史上下文。以后若要把其中的通用方法交给学习者，须另行登记输入范围，并对所有比较条件保持一致；目标网站真值、私有案例与评估信息仍须隔离。

本次核读了下列五篇论文的原文相关章节。这里的“核读”指确认所引用的定义、机制、假设和限制，不表示重新证明定理或复现作者实验。本文件不包含目标网站源码分析、网站规则、选择器或任务执行脚本，也不表示已经实施下一轮实验。

## 阅读目的与术语

当前问题不是先选一个方便的 AX 摘要，而是研究：在声明的观察接口、任务范围和预测时域内，何种表示保留了必要的行为差异，何种合并会造成误解。

- **观察**：本次可取得的 AX、DOM、截图及协议允许的其他信息。观察不是完整网站状态。
- **历史**：到当前时刻为止的动作与观察序列，可能包含一次页面快照没有表达的事实。
- **表示/抽象**：从观察或历史构造的模型输入、状态或事件类别。它本身是待检验的设计。
- **独立判据**：由评估侧注册并从真实环境取得的结果，不能由被测抽象决定哪些差异算正确。
- **区分性反例**：被表示合并的两种情况，在同一注册动作或后续动作序列下出现应当区分的结果。需先排除执行偏差、重置失败和环境变化。

下文每篇均区分“原文机制与前提”和“我们的网页实验提案”。后者是研究设计推导，不是论文已经证明的网页结论。

| 引用 ID | 主要阅读问题 | 不应误用成的主张 |
| --- | --- | --- |
| `BISIMULATION` | 何种状态合并保留动作后果和策略价值？ | AX 相似即可合并，或有限样本已经证明全局等价 |
| `POMDP` | 当前观察不充分时，历史与不确定性如何进入状态？ | 写了 unknown 就已实现正确 belief 更新 |
| `PSR` | 能否以未来实验结果的预测组织状态？ | 任意几个预测字段都是充分状态 |
| `CEGAR` | 有具体模型时，如何消除抽象产生的伪路径？ | 任意经验模型都具有保守抽象的证明能力 |
| `AUTOMATA-CEGAR` | 黑盒学习中，如何用冲突行为精化事件抽象？ | 一般异步网页满足确定、可重置的受限自动机假设 |

## BISIMULATION

**文献。** Robert Givan、Thomas Dean、Matthew Greig，2003，*Equivalence Notions and Model Minimization in Markov Decision Processes*，Artificial Intelligence 147(1–2)，163–223。

- 正式 DOI：[10.1016/S0004-3702(02)00376-4](https://doi.org/10.1016/S0004-3702(02)00376-4)。
- 已核读作者 PDF：[Brown University 作者稿](https://cs.brown.edu/people/tdean/publications/archive/GivanetalAIJ-03.pdf)。
- 正文定位：§3.3，作者稿第 13 页的 stochastic bisimulation 定义；第 14 页 Theorem 7；§4 的分区精化。作者稿页码与期刊页码不同。

### 原文机制与前提

论文用随机双模拟定义可聚合的 MDP 状态：同类状态奖励一致；对每个动作，转移到各个等价状态类的概率一致。由此构造的商模型保留相应的最优策略。分区精化将奖励或转移行为不同的状态拆开。

这里的保证针对给定 MDP、动作空间与满足定义的关系。仅有相同即时奖励不够；后续转移也必须满足条件。有限轨迹中没有发现差异，不等于已经检查了所有状态与动作。

### 不能据此推出什么

论文没有给 AX 树定义天然的等价距离，也没有证明任务成功这一标量足以代表网页的全部语义。若关注对象身份、拒绝原因或副作用，这些区别必须进入所要保留的性质；不能在评价时临时略去。

### 我们的网页实验提案（非理论保证）

把每次状态合并作为可反驳声明。对模型归为同类的两个前态，提供同一动作，比较独立取得的结果、业务对象、禁止副作用和下一步可操作性。增加短序列检查，以寻找单步结束时尚未显现的差异。

相反方向也要测试：页面存在装饰或排版变化时，若注册的行为性质相同，表示是否仍产生不必要的拆分。这样同时观察信息损失和无谓复杂度，而不是单独奖励压缩。

建议记录：合并依据、比较的具体状态对、动作序列、结果判据、首次分歧位置、排除的执行故障，以及尚未探索的分支。结论限定为指定测试分布内发现或未发现反例，不能使用“已证明网页双模拟”。

### 复习问题

1. 两个状态的即时结果相同，为什么仍可能必须拆开？
2. 我们要求保留哪些性质？它们由谁登记，是否独立于被测表示？
3. 某个动作在一个状态可用、另一个不可用，这个差异会落到哪项判据？
4. 如果只在一个对象和一条路径上验证，哪些合并仍然没有证据？

## POMDP

**文献。** Leslie Pack Kaelbling、Michael L. Littman、Anthony R. Cassandra，1998，*Planning and Acting in Partially Observable Stochastic Domains*，Artificial Intelligence 101(1–2)，99–134。

- 正式 DOI：[10.1016/S0004-3702(98)00023-X](https://doi.org/10.1016/S0004-3702(98)00023-X)。
- 已核读作者 PDF：[MIT 作者全文](https://people.csail.mit.edu/lpk/papers/aij98-pomdp.pdf)。
- 正文定位：§3.2–3.4，期刊第 106–108 页；§3.3 的 belief 更新；第 108 页对正确转移、观察模型的条件说明。

### 原文机制与前提

belief 是给定历史后的隐藏状态概率分布。通过前一 belief、动作和新观察递归更新，正确计算的 belief 才构成历史的充分统计量。只保留最可能状态通常不足，因为行动也需要考虑不确定性和获取信息的价值。

相应保证依赖正确的状态、转移与观察模型。论文不是说任意历史摘要都充分，也不是从页面信息自动学出完整隐藏状态的保证。

### 不能据此推出什么

AX 完全一致不能证明后台状态一致；反过来，加入历史字段也不自动消除部分可观测性。写入“未知”只是表达尚未确认，并不等价于已维护了正确的概率分布。网页异步行为是否可以通过有限状态建模，需要另行检验。

### 我们的网页实验提案（非理论保证）

为表示选择设置配对场景：当前允许观察相同或近似，前序交互不同，后续结果可能不同。比较只用当前观察、使用有限历史、使用显式不确定状态的候选表示。

评估者可以通过特权信息确认两例后台情况确实不同，但不能把该信息交给学习者。若协议允许的整个历史都不能区分两例，就不应强迫模型给出确定预测；可以预先登记概率、结果集合或拒答的评分方式。不能在看到答案后才放宽预测解释。

将“缺少观察”与“规则错误”分开记录。允许模型提出需要补充的公开观察，另计其信息获取成本；观察后仍不确定时保留未知，不能让检查器替它补全知识。

### 复习问题

1. 当前 AX、交互历史、真实后台状态分别是什么对象？
2. 两例对学习者不可区分时，怎样评价预测才不把隐藏真值当可用输入？
3. 不确定来自环境随机性、未观察状态，还是模型本身尚未学会？
4. 新增一个历史字段后，有什么未见案例能检验它是否足够？

## PSR

**文献。** Michael L. Littman、Richard S. Sutton、Satinder Singh，NIPS 2001，*Predictive Representations of State*，Advances in Neural Information Processing Systems 14，1555–1561。

- 正式论文页面：[NeurIPS 2001 论文条目](https://papers.nips.cc/paper_files/paper/2001/hash/1e4d36177d71bbb3558e43af9577d70e-Abstract.html)。
- 已核读正式 PDF：[NeurIPS 原文](https://proceedings.neurips.cc/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf)。本次未核实到 DOI，不补造。
- 正文定位：§1 的 test 与预测向量定义、公式 (1)–(3)；§2 的 Theorem 1；引言对学习方法尚待研究的说明。以章节和公式定位，避免扫描 PDF 的空白页造成页码歧义。
- 署名核对：PDF 包含 Satinder Singh；不能仅依赖网页条目显示的前两位作者。

### 原文机制与前提

PSR 用一组未来动作—观察序列的预测概率表示状态。一个合格的核心测试集合应足以决定所有其他测试的预测，并可在新动作和观察后更新。论文给出有限 POMDP 存在线性 PSR 的结果，所需核心测试数量不超过最小 POMDP 的状态数。

这是表示存在性和构造结果；不是任意小预测向量的充分性，也不是已经解决从少量黑盒数据发现核心测试的问题。

### 不能据此推出什么

预测受理/拒绝、是否变化和变化数量三个字段，不能仅凭格式相似就被称为 PSR。若所有保留字段都忽略了某种业务差异，内部回放正确仍可能无法支持后续任务。原文并未直接研究 AX、网页对象或网页脚本。

### 我们的网页实验提案（非理论保证）

把“值得记住什么”转换成“哪些未来实验需要区分”。候选状态可包含对公开动作后果的预测及其证据范围，而不仅是页面的压缩描述。测试集合仍须由学习过程和注册方法产生，不能从私有评分答案倒推。

用未参与构建表示的短动作序列作挑战，分别报告一步和多步预测。遇到相同预测向量却产生不同后续行为的情况，保存对应序列，检验新增区分测试是否能改善邻近未见案例。

可比较表示大小、信息获取成本、预测覆盖及误差随序列长度的变化。有限测试只提供经验充分性证据；不能把“当前测试集都通过”改写成“可预测所有未来”。

### 复习问题

1. PSR 的 test 为什么包含动作序列，而不只是下一张页面？
2. 哪个多步实验可能区分当前三个评分字段看不出的状态？
3. 核心测试的选择是否已经接触私有答案？
4. 新增预测字段是在表达新的行为差异，还是记住某个样本标识？

## CEGAR

**文献。** Edmund Clarke、Orna Grumberg、Somesh Jha、Yuan Lu、Helmut Veith，2003，*Counterexample-Guided Abstraction Refinement for Symbolic Model Checking*，Journal of the ACM 50(5)，752–794。其前身发表于 CAV 2000；本次核读的是 2003 年扩展全文。

- 正式 DOI：[10.1145/876638.876643](https://doi.org/10.1145/876638.876643)。
- 已核读作者 PDF：[CMU 作者全文](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/Counterexample-guided%20abstraction%20refinement.pdf)。
- 前身出版标识：[CAV 2000，10.1007/10722167_15](https://doi.org/10.1007/10722167_15)；不将扩展版 PDF 标成已核读的会议版正文。
- 正文定位：§1.1，期刊第 754–755 页；§4.3 的反例检查；§4.4，尤其第 777 页的状态拆分说明。

### 原文机制与前提

方法从具体系统构造保守的过度近似，检查指定逻辑性质。抽象路径可能没有对应的真实路径；此时通过分析伪反例，拆分被错误合并的状态，排除该伪路径。相应性质保持结论依赖具体模型、模拟关系及所用逻辑范围。

这与“观察到真实结果和学习模型预测不同”并非同一种反例。后者既可能是合并过粗，也可能是学习模型漏掉转移或实现错误。

### 不能据此推出什么

黑盒模型未必覆盖真实系统的全部行为，不能自动当成过度近似。一次执行未复现路径，也不能证明该路径不可能。因此浏览器经验精化不能直接继承模型检查中的正确性结论。

### 我们的网页实验提案（非理论保证）

沿用反例驱动的工作方式，但保留两类记录：真实网站行为反驳学习假设；抽象推演产生无法在注册环境中确认的路径。两者都先排查脚本、时序、版本和重置问题。

精化前保存原模型、最小分歧轨迹及候选原因；精化后记录新增的状态条件、历史或预测分支。用原反例回归和未参与修订的相邻实例验证。不要只检查修订后的内部测试，也不要把修订成绩计入冻结首次泛化。

报告修复成本、仍未解决的歧义、误伤的既有能力。只在具备具体模型和相应证明条件时使用正式“性质保持”说法；其他情况标为经验反例精化。

### 复习问题

1. 这里的反例是实际发生的行为，还是抽象模型多出来的路径？
2. 什么证据支持“不可实现”，而不仅是“这次没执行出来”？
3. 修复改变了抽象、规则、执行代码，还是检查器？
4. 哪些结论需要保守过度近似，而我们目前没有该条件？

## AUTOMATA-CEGAR

**文献。** Fides Aarts、Faranak Heidarian、Harco Kuppens、Petur Olsen、Frits Vaandrager，2012，*Automata Learning Through Counterexample Guided Abstraction Refinement*，FM 2012，LNCS 7436，10–27。

- 正式 DOI：[10.1007/978-3-642-32759-9_4](https://doi.org/10.1007/978-3-642-32759-9_4)。
- 作者出版页面：[Radboud 文献条目](https://sws.cs.ru.nl/publications/papers/fvaan/CEGAR12/)。
- 已核读作者 PDF：[FM.pdf](https://sws.cs.ru.nl/publications/papers/fvaan/CEGAR12/FM.pdf)。
- 正文定位：作者 PDF 第 1–3 页引言与适用限制；§3.1 的查询和重置，§3.3 的 mapper；§5 与 Algorithm 1；第 16 页的随机测试和另行等价检查说明。作者 PDF 为 17 页，勿直接用其页码替代正式出版页码。

### 原文机制与前提

带历史状态的 mapper 把大量具体输入映射成少量抽象事件。确定系统若因过粗映射而表现出冲突输出，就精化参数区别。Tomte 结合 LearnLib 学习受限 scalarset Mealy 模型：数据仅做相等性测试；原型只记参数首次和最近出现，不支持一般算术。

形式查询包含重置和包含性检查；实际学习用测试近似后者。作者实验另外借助可得模型及 CADP 检查等价，不能将这一额外验证等同于随机测试未发现反例。

### 不能据此推出什么

网页的超时、并发、后台任务和不完整重置都可能产生冲突。不能一见不同输出就断定抽象有错，也不能把无冲突当成全局正确。文中的输出可预测 mapper 对输出的保留有条件；不能任意折叠输出后宣称保持原行为。

### 我们的网页实验提案（非理论保证）

这篇比源码模型检查更贴近浏览器黑盒学习：保存两条被当前表示合并、却产生不同输出的具体轨迹，主动查找需要保留的参数关系或历史区别。对象关系可作为候选抽象，例如是否指向先前观察的同一对象，但是否成立由实验模型提出和证据检验，管理方不替网站补规则。

复现冲突时先确认业务初态、浏览器状态、执行动作和环境版本。若差异仍来自不可见状态，转为部分可观测问题；若是真正随机过程，采用分布检验；若是表示漏掉关系，再提出精化。精化后的测试应包括新的对象与参数，而不是只重放原冲突。

将随机探索次数、发现的冲突、精化次数、重启学习成本和独立验证分别记账。不能把有权威模型的作者案例结论移植到无完整源码/等价 oracle 的网页实验。

### 复习问题

1. 两条轨迹在抽象层相同，具体层究竟有哪些差别？
2. 相同输入输出冲突是否可能由未排空的请求或不完整重置造成？
3. 对象关系相等性足够吗，还是当前业务需要数量、顺序或算术？
4. 学习过程中的测试近似和事后的独立等价检查有什么区别？

## 五篇共同支持的实验问题（我们的提案）

应先探索表示，再决定采用哪种规则书和可执行模型格式。以下问题适用于候选格式比较，不预先指定网站模型必须长什么样。

| 问题 | 可采集证据 | 不允许的替代证据 |
| --- | --- | --- |
| 表示是否误合并？ | 同类前态在同动作/短序列下的独立结果分歧 | 摘要相似或 AX 字符串相同 |
| 表示是否拆得过细？ | 外观变化但注册行为相同的配对案例 | 主观认为某 DOM 字段“不重要” |
| 是否缺少历史？ | 当前观察相同、历史不同的预测对照 | 后台真值直接作为模型输入 |
| 是否只会一步回放？ | 未用于建模的多步区分序列 | 用训练轨迹再次验证内部一致性 |
| 精化是否改善规律？ | 原反例修复、邻近未见实例和既有能力回归 | 仅增加一个样本特判后宣称理解完成 |

建议将原始观察、表示产物、表示版本、模型预测和独立结果分开保存。压缩比、token 成本、延迟可以衡量代价；正确率、未知覆盖、误合并反例与回归损失衡量行为保留。两类指标都需报告，不能用一种抵消另一种。

测试判据不能完全由被测表示定义。如果抽象把某字段删掉，评分器也跟着不检查该字段，就可能把信息丢失藏进评价标准。注册的业务目标、对象身份、关键 UI 状态与禁止副作用由独立评估侧维护；不能预见的实际分歧作为新反例单列，不回写原始冻结分数。

这些文献提供的是形式目标、假设提醒和可操作的反例思路。有限网页实验能够报告指定范围内的预测与执行证据、发现的抽象缺陷以及修正效果；不能据此宣称已经证明完全理解、全站行为等价或存在最优规则书格式。
