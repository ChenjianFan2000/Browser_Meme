# 国内镜像下载与安装

2026-10-15 已完成三套运行环境安装与浏览器测试，站点镜像仍待下载。所有入口都在 `G:\Browser_Meme\environment`；请保留现有 `.runtime` 目录，已有环境、下载和缓存均在其中。

## 先运行这个

双击 **[Complete-Runtimes-CN.cmd](Complete-Runtimes-CN.cmd)**。

它会按顺序准备、下载、安装并检查 core、agentlab、webchore 三套环境，复用已完成的包。本机三套环境均已通过检查，无需为下载站点镜像重跑此入口。这个入口**不下载约 210 GB 的站点镜像**。

也可在 PowerShell 执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File G:\Browser_Meme\environment\Complete-Runtimes.ps1 -Mirror cn
```

## 使用的下载源

| 内容 | 国内优先来源 | 失败后的来源 |
| --- | --- | --- |
| Python 依赖 | 清华 PyPI | 官方 PyPI |
| CPU PyTorch | 上海交大镜像 | PyTorch 官方 |
| Chromium | npmmirror | Playwright 官方 CDN |
| 独立 GitLab 镜像 | DaoCloud | Docker Hub |

NLTK 资源已有经过哈希校验的缓存；缺失时使用 jsDelivr 公共 CDN 和上游 GitHub，不能保证国内直连速度。所有来源沿用固定版本和哈希检查；实际速度取决于你届时的网络。

## 大镜像单独运行

只有需要完整自托管站点时，再双击 **[Download-Images-CN.cmd](Download-Images-CN.cmd)**。约 209.86 GB 的下载量另加 Docker 解包空间；其中四个 WebArena 归档约 208.41 GB，仍使用上游 Google Drive，尚无已验证的国内替代源。

下载成功后，双击 [Install-Images.cmd](Install-Images.cmd) 离线导入；站点启动命令见 [README](README.md#启动本地站点)。旧入口 `Download-All.cmd` 也会下载这批大镜像，请按需要选择。

如果看到 `Missing or unverified image archives`，表示导入时缺少完整且经过校验的镜像文件。先运行 `Download-Images-CN.cmd`，等它提示下载成功后，再运行 `Install-Images.cmd`。`Complete-Runtimes-CN.cmd` 完成不代表站点镜像也已下载。

## 中断后继续

- 重新运行同一个入口，已校验完成的文件会复用，支持续传的传输保留断点。
- 网络超时会重试；G 盘消失会等待原盘恢复，并尝试恢复本项目的 WSL 发行版。超出次数后明确退出。
- pip 的传输重试与 HTTP / Google Drive 续传方式不同；强制关闭进程后，尚未完成的单个包或浏览器组件可能重新下载，已完成的阶段保留。
- 进度见 `.runtime\logs\*-download-recovery.log`，阶段状态见 `download-state.json`。不要同时开启多个下载入口。

脚本、下载、缓存和环境均放在 G 盘。运行环境入口已成功执行；站点镜像下载入口的准备步骤已通过检查，约 210 GB 的实际传输尚未验证。
