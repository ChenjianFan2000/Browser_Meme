# 第二阶段：浏览器信息可见的独立探索与建模

协议编号：`phase2-discogs-20261021-01`。登记日期：2026-10-21。
用户已授权按上一轮确认方案完整实施。本文件登记准备、隔离验收及预实验条件；
正式学习须先完成本文件规定的就绪清单并冻结实际实现和环境。准备完成不算实验完成。

## 研究问题与历史边界

在固定的本地 Discogs 派生站点、普通测试账号和可访问页面范围内，独立
`gpt-6.1-sol` 能否只通过浏览器观察及交互形成带证据的规则和必要的可执行行为模型，
并对未见参数、对象和状态作出正确预测？比较同等预算下移除可执行行为模型的条件。

这不是官方基准成绩、全站覆盖、严格速度对照或第三阶段组合泛化成绩。
阶段一源码可见结果保留原解释；旧模型、旧规则、旧任务解答和旧轨迹不交给学习者。
主 Agent 已接触阶段一结果及管理信息，不能充当学习者，也不编写网站规则、选择器、
预测或任务脚本。另一个独立 Solar 上下文负责部署与私有评价，不参与学习建模。

## 模型、分组与重复

- 学习者固定 `gpt-6.1-sol`，每轮全新上下文、自己的工作目录和浏览器状态。
- 首先运行 `pilot-001`，仅用于协议与接口可用性检验；其上下文和学习产物不进入正式轮。
- A 组：自然语言规则书、可执行行为预测模型、原生 Playwright 执行脚本。
- B 组：自然语言规则书、原生 Playwright 执行脚本；不提供或生成可执行行为预测模型。
- 两组均允许 LLM 持续监督、计算、同等形式的持久记忆和浏览器反馈。
- 正式每组三轮，管理随机种子为 1729、2718、3141。种子控制本地调度/抽样；
  模型服务若不暴露采样种子，记录 `model_sampling_seed=null`，不声称模型调用可确定重现。
- 同一种子两组从相同数据库快照开始，运行串行，避免共享数据库的重置相互影响。
- 模型、推理设置、真实工具列表、启动通道和可见输入的哈希必须在实际运行前登记。
  模型不可用时不替换，不由协调者接管建模。

## 允许信息与动作

允许按需读取页面 DOM 的结构、属性、可见状态、无障碍信息、截图及 UI 交互自然
产生的同源脱敏网络响应。首轮不向学习者提供客户端 JavaScript 正文、source map、
本地前后端源码、数据库、后台观察、评估器、测试答案或阶段一网站资料。
DOM/trace 的学习者可见副本必须执行同样的限制；管理侧可以保存隔离的原始证据。

执行采用原生 Playwright 脚本和定位器；模型能自行发现新的页面、对象和操作，
不被限制为管理者预设的网站动作。业务动作通过 UI，禁止直接 API 业务写入、
DOM 篡改伪造结果和请求拦截伪造成功。观察范围的任何扩展必须另记协议，不能混计。

脚本按“确认目标→滚动至可见→操作→有界等待→回读验证”记录；导航没有滚动目标。
每次动作前登记候选假设、预期结果或未知，动作后保存符合/矛盾/无法确认。
定位、时序、实现和业务规则问题分别诊断；未确认的非幂等写入不得自动重放。

## 强制隔离门槛

正式学习者及其全部可用文件、命令、工具、进程和网络通道都必须受实际权限控制。
独立上下文、提示禁令、Python facade、AST 白名单和文件夹分离均不等于强制隔离。
仅隔离 Playwright、而模型仍可调用宿主机全权限工具，不得通过本门槛。

必须保存实际正反例：允许工作区读写、受控浏览器正常运行；拒绝源码、历史模型、
私有评估、凭据/宿主历史、越界路径、其他管理端点及不允许的网络访问。
还须检查额外 MCP/插件、子进程、自动加载的文档/记忆及模型可用工具清单。
验证者记录实际权限配置、运行身份、平台版本、命令、退出码和证据哈希。
任何未通过项阻止正式学习，不能靠将规则写进提示词放行。

本机部署与评价保留在管理侧，模型执行进程不加载站点评估器。
数据库重置属于管理操作；后台真值只用于独立评价，不作为学习反馈。
如需管理停止，只向学习者交付通用停止事实和允许范围内的浏览器证据。

## 预算与停止

| 条件 | UI动作上限 | 模型交接上限 | 总时限 |
| --- | ---: | ---: | ---: |
| 预实验 | 100 | 40 | 3600秒 |
| 正式每轮学习 | 300 | 40 | 7200秒 |

任一上限到达即停止并冻结当时产物。Playwright 单操作及导航超时30秒。
动作指实际派发的导航、点击、输入、选择、按键等 UI 操作；观察和计算另计。
自动等待、重试、回读、监督和修订纳入实际耗时，失败动作保留。
模型交接次数与底层推理请求数分别记录，不把工具调用数充当模型调用数。
模型调用次数、token、费用不可观测时使用 null，不估算账单。
越界、未知写入、环境故障、模型不可用、预算用尽或证据缺失均保留明确停止原因。

## 学习流程与产物

学习者主动完成“发现→竞争假设→区分性实验→先预测→执行观察→修订”。
探索成功、拒绝、边界、重复及短组合，保留尚未探索页面与未知规律。
已验证规律必须限定证据支持的角色、状态及参数范围，不能从一次成功推导全站结论。

产物包括规则书、对象/页面/操作映射、可执行行为模型（仅A组）、原生任务脚本、
证据引用、覆盖与未知清单、反例及父子版本链。规则引用浏览器 `evidence_refs`，
不要求也不允许从历史源码填入 `source_refs`。
行为模型与任务执行脚本分开；模型内一致性与历史回放不替代真实网站独立验证。

## 私有冻结测试

独立评估员准备30例固定清单：新参数10例、新状态10例、拒绝/边界10例。
学习者只获得当前待执行任务的 `id/goal/parameters`，没有步骤、选择器或参考答案。
私有清单、初始化状态和评价实现须在正式学习前冻结；就绪检查不足时不能称为可运行。
保留已知站点阻碍例，不能为提升成绩删除失败、拒绝、未知、超时或未执行例。

冻结模型测评不得修改学习规则和行为模型，也不得跨测试实例传递测试反馈。
允许当前任务内 LLM 监督及临时脚本生成；公开观察仍服从本协议。
每例新浏览器上下文，管理侧恢复对应初态；两组使用等价初态和终点条件。
预测在动作前保存；任务完成、业务生效/拒绝、状态变化及无关副作用由独立评价确定。
未知和不可评分字段单列，不计为预测正确；拒绝预测正确与业务目标达成分别报告。
测试反例用于修订后只能计入适应结果或新运行，不能追溯修改冻结首次成绩。

## 统计、交付与第三阶段

每轮报告固定分母下的预测正确/错误/未知/不可评分、任务结果、覆盖与未知、
实际交互/观察/模型交接预算、时间、反例与修订。先分别列出三轮，再汇总；
不把相关实例当作独立训练重复，不从这些测量生成严格速度加速比。

预留未演示组合按工作流模板分组，不跨学习和测试集合。第三阶段接收冻结模型及
边界清单，首次组合泛化与后续在线适应另行登记和评分。

完成判据：隔离验收通过；预实验完成；两组各三轮独立学习与30例冻结测评完成或
按协议完整保留停止/失败；规则与模型证据可审查；独立评价、版本和环境完整性通过；
发布结果及第三阶段交接包。基础设施阻塞不能伪装为已完成学习或零分模型结果。
