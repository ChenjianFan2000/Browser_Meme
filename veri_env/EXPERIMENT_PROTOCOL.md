# 本地 issue 管理世界模型对照实验

本协议在模型生成和测试成绩产生前固定。实验使用本地可重置的 issue 管理应用，与 VeriEnv 的环境、SDK、确定性验证接口对接；不使用 WebArena、ServiceNow 账户或真实 GitLab 服务。它是 issue 管理业务的派生微型实验，不报告为上述官方基准成绩。

## 研究问题

1. 相同观察证据下，可执行模型能否预测新对象、新状态中的操作后果？
2. 在不提供中间真实观察时，模型能否预测未演示的操作组合？
3. 操作规则改变后，少量反例能否改善预测，并保持原有能力？

本轮明确提供固定动作接口与完整的可观察业务记录，重点隔离行为规律学习。它不检验控件自主发现、视觉定位、隐藏状态辨识、真实 GitLab 泛化或长期在线学习。

## 环境与信息边界

环境包含六条 issue、状态与标签筛选、排序、选择、批量标签、关闭、重开和评论。业务状态以浏览器可展示的记录和界面状态表达。学习者可以看到初始记录、允许的动作格式、历史动作与后果；不能读取环境实现、评测器、测试答案或隐藏规则版本。

环境内部保留规则版本。版本变化涉及关闭操作的条件与筛选后的选择状态。变化的具体规则不放入学习请求，而由公开的适应轨迹提供证据。本协议与环境源码也不发送给实验模型。

独立评测器直接查询真实环境产生的结果，不使用待测模型或其自行生成的判定器作为正确答案。生成代码只允许无文件、无网络的确定性计算；每个产物保留原文、模型名称、父请求、时间和哈希。

## 数据划分

- 学习：固定种子 11、23、37 的操作轨迹，涵盖所有动作、权限与成功/失败反馈。
- 开发：种子 41、43，用于至多一次修正；不用于最终成绩。
- 固定模型测试：种子 101、103、107；24 个一步预测样本与12个2至4步开放环组合。
- 变化适应：种子 71、73，六条公开的新规则转移；模型允许再修改一次。
- 变化测试：种子 211、223、227，12个样本；分别用变化前、变化后模型评测。
- 保留能力：修正后重新评测原规则测试集，同时说明两规则是否冲突，避免把应当发生的规则替换误判为遗忘。

种子固定数据与任务，不保证托管 LLM 的采样可复现。模型输入与完整输出保存后，可以不再调用 LLM 重放评分。

## 方法与复现层级

纳入本轮文献调研发现且可获取公开源码的直接相关项目。原始文件下载后固定 commit 和文件哈希。源码本身的执行检查、核心算法的子域移植、仅依照论文的机制实现分别记录。

VeriEnv 提供训练环境和验证机制，不等同于预测器。它的克隆环境路线可作为代码模拟器条件，其原版拒绝采样微调流程单独标记。WMA、WebEvolver 等依赖专用训练权重；用 Luna 替换其预测器的实验属于推理组件适配，不能称原版复现。只运行了导入或辅助函数的项目不得填写预测成功率。

加入 Luna 直接预测、与当前研究目标对应的规则记忆及代码修正方法。保留同样训练证据、观察字段、测试案例、输出要求和失败处理。不同表示产生的模型调用数量分别计量，不强行伪造相同训练计算量。

## 模型与预算

实验模型使用本会话授权的 `gpt-6-luna` 子代理。各方法从不继承父对话的独立会话开始，只读取专门导出的公开请求包。生成式代码方法最多一次初始生成、一次开发集修正、一次规则变化修正。需要在线 LLM 预测的方法按其每次预测调用计量。任何新增方法、样本调整和实现修正均记录为协议修订，不隐瞒失败后更改。

本轮是一轮工程与方法可行性实验。每个学习产物一次生成，不凭少量案例声称统计显著或优于原论文。记录实际可获取的调用数、输入输出字节数、墙钟时间；若子代理没有提供 token/费用账单，就不报告臆算的真实 token 或费用。

## 指标

- 可执行率：模型能否接受约定输入并返回合法观察。
- 一步业务状态完全匹配率；反馈、记录和界面状态分项匹配率。
- 多步开放环：最终状态匹配率与逐步匹配率。
- 变化前后匹配率及绝对变化；适应证据数量与修改次数。
- 调用数、模型生成时间、纯代码预测耗时。浏览器执行耗时另报，不能把代码推演延迟称为网页任务端到端速度。

未运行、依赖不满足、生成失败、接口失败和业务预测错误分别保存。训练/开发集上的成绩只用于诊断，不能作为测试泛化成绩。

## 产物

`LITERATURE_REVIEW.md` 汇总文献方法和原始实验；`SOURCE_MANIFEST.json` 与 `SOURCE_AUDIT.md` 记录代码；`issue_lab/` 提供环境与实验工具；`artifacts/` 保存数据、模型请求、模型输出及逐例结果；`EXPERIMENT_RESULTS.md` 汇总本次实际测量。

## 协议细化记录（2026-10-20）

在仅查看 current 和 PatchWorld 的开发集结果之后、其他方法生成及任何最终测试评分之前，固定如下适配边界。原始数据与测试数量不变。

- 可执行条件为 current、VeriEnv 行为克隆、WorldCoder、PatchWorld、GIF、PoE 和 Agent2World 的七种子域派生实现。除明确接入的原版组件外，不称完整算法复现。尤其 GIF 只有一个候选与一次修正，没有 MCTS 分支搜索；PoE 为确定性属性专家，没有概率权重训练；Agent2World 仅用 code-agent 提示与独立反馈，没有完整多代理研发链。各条件实际来源见 `artifacts/method_registry.json`。
- 直接预测条件为 Luna Direct、WMA、WebDreamer、WebEvolver、WebWorld 的推理提示适配。每个条件一次请求批量提交 48 条轨迹预测，适应阶段再批量提交 36 条（一步与变化测试）。这是会话内批量预测，不是每一步独立 API 请求。不提供开发反馈；其相同学习证据的比较对象是代码方法的 initial 版本。代码方法 repaired 版本另列，不能把额外开发反馈算作等预算优势。
- 直接预测仅接受公开初始观察和动作；案例 ID 改为不含任务、划分、种子或版本信息的散列并按散列排序。输出为无损状态差分。多步预测不得获得真实中间观察。新规则六条证据在初次预测提交后才开放。
- Code2World 的截图→HTML 输出与本轮业务状态转移指标不等价；将其纳入源码与原生接口执行检查，预测成绩留空。不能把另写的 JSON 预测器改名为 Code2World 来补齐表格。运行其原本任务仍需 AndroidWorld、专用 checkpoint 和截图渲染。
- 未变化能力只统计旧版一步测试中除筛选规则变化以外的 21 条。旧版多步流程含被替换的关闭规则，不将其适应后下降称为遗忘。旧版一步开发/测试共享操作模板但对象种子不同，故只支持参数/状态迁移；组合测试才使用未演示的多步序列。
- 调用数按实际子代理学习/预测回合记录。原始产物保留；没有 token/账单数据，不声称累计 token 严格相等。请求导出到产物落盘的间隔包含调度等待，只作工程记录，不当作模型纯推理耗时。

评分实现审查记录：最终评分使用严格公开schema，并通过JSON哈希区分布尔/整数、大小写和空白。首次重放后，适配器修复UTF-8 BOM读取问题；计时增加仅包围predict函数调用的字段，重新重放相同冻结产物，业务分数须保持不变。原 `seconds/cpu_wall_seconds` 包含校验和判定开销，不能解释为纯预测延迟。直接预测的该计时只是离线差分应用，不包含Luna推理。模型白名单是静态约束而非操作系统安全沙箱；子代理依据指令隔离读取，未建立强制文件访问隔离。
