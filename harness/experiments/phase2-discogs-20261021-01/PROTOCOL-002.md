## 独立模型及隔离实现

实验模型仍固定为 `gpt-6.1-sol`，推理设置 `high`。启动方式是独立 Codex CLI 0.163.0 子进程，
每轮全新上下文、工作目录及仅含认证文件的新配置目录，不继承主 Agent 的对话、网站推理或历史规则。
这是独立实验子进程，而不是具有宿主全部工具权限的 `collaboration.spawn_agent` 会话；实际通道如实记录。
不把一个独立上下文当成强制隔离。

学习者命令工具采用 Linux 文件、进程和网络 namespace：默认拒绝文件，只开放最小运行环境和自己的工作目录，
无目标站点 TCP 或 Unix socket，无源码、旧实验、数据库、评测器、宿主凭据或后台端点。
关闭协作接口、其他应用与插件、网页搜索、历史记忆、技能正文/目录及项目文档自动加载。
模型传输由可信 CLI 处理，工具环境不获得模型服务网络权限。

唯一新增工具为通用浏览器 MCP。模型提交自己的原生 Playwright 脚本，可信 broker 在第二个受限 Linux namespace 中运行。
该执行进程只额外取得通用运行代码、固定 Playwright/Chromium、自己的临时目录和单站点 Unix socket。
Windows 与 WSL 之间通过 stdio 转发固定站点，不为学习者开放宿主网络端口。
native Playwright Page/Locator 保留；不存在预设网站业务动作或重标号元素接口。

AST 检查和原生方法过滤用于限制观察 API，**不是操作系统沙箱**；文件、进程及网络边界另有真实隔离。
任意 JavaScript 求值、客户端代码正文、原始请求 API、请求篡改、内部对象反射及原始 trace 读取不在模型接口内。
DOM、AX、截图及 UI 产生的同源响应经脱敏导出，原始轨迹与浏览器认证状态保留在管理侧。
最终机器验收记录及关键代码哈希必须通过，启动器才允许开始学习。失败探针保留，不记为学习结果。

## 执行和记录

预实验使用 100 个 UI 动作、40 次浏览器脚本执行、3600 秒上限；正式每轮 300 个 UI 动作、
40 次浏览器脚本执行、7200 秒。模型会话交接数与工具调用数另记，不能互相替代。
这些是上限；允许提前交付完整但覆盖有限的诚实模型。模型服务调用数不可观测则为 null。

每次原生动作前必须先调用通用 `expect`，持久保存模型预测；动作后保存页面回读、截图和网络证据。
单动作与导航 30 秒超时，正常动作后固定 250 毫秒等待，模型可用有界条件补充等待。
单脚本上限 300 秒；等待、自动重试、监督、纠错都计入耗时。不能确认写入效果的超时停止该轮执行。
学习期间网站状态与浏览器 cookies/local storage 持续；每个脚本启动新页面，须显式导航。
正式轮之间恢复基线并使用全新浏览器状态。

模型输出保留版本，管理侧只验证结构、哈希、预算和证据，不补写网站规则、选择器、预测或任务脚本。
A 组必须包含独立可执行预测模型；B 组只保留自然语言知识与 UI 脚本。
两组学习过程都保留同一 LLM 监督和同等浏览器信息。

## 冻结评价边界

每轮学习包先冻结，再交付公开任务的 `id/goal/parameters`。允许冻结后一次性生成 30 例执行计划；
须登记全部测试目标同时公开，后续不得据此修订学习模型并称为首次泛化。
执行仍逐例恢复私有初态、使用新浏览器上下文，并保留全部 30 例分母。
任务预测必须在相应业务动作之前冻结；独立评价从真实请求和后台状态确定结果。
任务级预测与动作级预测分开，不能互作分母。

新颖性不能只靠文件搜索未命中证明。必须对照冻结前探索证据审核参数、状态及操作是否已出现；
无法确认的案例保留成绩，但不声称是已证明的未见泛化。第三阶段组合任务另行划分并登记。

本补充不预填正式成绩，不把环境验收、隔离检查或预实验当成正式学习重复。
